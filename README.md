First project for a subject called Algorithms and Complexity at Vistula University. The project's task is to study different algoritms complexity on practice and then compare them with each other. Project was programmed using Java 21. Libraries used: Swing and AWT. IDE: Intellij IDEA Community Edition 2024.1.2. Algoritms used for analysis: HeapSort, MergeSort, BubbleSort, QuickSort. You can find the full report(written in Polish) in the main branch in docx or pdf. 



HOW TO RUN THE PROJECT
1) Firstly you need to install Java SDK 21 by following this link: https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html
2) Then download Intellij IDEA Community Edition 2024.1.2 by gollowing this link: https://www.jetbrains.com/idea/download/other/#releases-2024
3) After that clone this project onto your PC and load the folder from IDE.
4) Wait for SDK setup to finish or/and for some plugins to download
5) Lastly, hit green run button
